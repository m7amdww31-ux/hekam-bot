# بوت الحكم والاقتباسات 🌙

بوت ديسكورد بسيط يرسل حكم واقتباسات عربية — **بأمر** وكذلك **تلقائياً** كل فترة.

## ✨ المميزات
- أمر `#حكمة` يرسل حكمة عشوائية على شكل إيمبد أنيق بلون ذهبي.
- تصنيفات: `#حكمة نجاح` (حياة، نجاح، علم، صبر، صداقة، وقت).
- إرسال تلقائي لقناة محددة كل فترة (افتراضي كل ٣ ساعات).
- أمر `#مساعدة` يعرض كل الأوامر.
- جاهز للتشغيل على Railway مباشرة.

---

## 🛠️ خطوات الإنشاء والتشغيل

### ١) إنشاء البوت في بوابة المطورين
1. ادخلي على `https://discord.com/developers/applications` واضغطي **New Application**.
2. من تبويب **Bot** اضغطي **Add Bot**، وانسخي الـ **Token** (هذا تحطينه في Railway لاحقاً).
3. مهم جداً: في نفس صفحة **Bot** فعّلي خيار **MESSAGE CONTENT INTENT** (بدونه ما بيشتغل أمر `#حكمة`).

### ٢) دعوة البوت للسيرفر
1. من تبويب **OAuth2 → URL Generator** اختاري:
   - Scopes: `bot`
   - Bot Permissions: `Send Messages` و `Embed Links`
2. انسخي الرابط الناتج وافتحيه واختاري سيرفرك.

### ٣) رفع الكود على GitHub
- ارفعي ملفات هذا المجلد كاملة في ريبو جديد (نفس طريقتك المعتادة من واجهة GitHub).

### ٤) النشر على Railway
1. ادخلي Railway → **New Project → Deploy from GitHub repo** واختاري الريبو.
2. من تبويب **Variables** أضيفي المتغيرات التالية:

| المتغيّر | القيمة | إجباري؟ |
|---|---|---|
| `DISCORD_TOKEN` | توكن البوت اللي نسخته | نعم |
| `QUOTE_CHANNEL_ID` | ID القناة للإرسال التلقائي | اختياري |
| `INTERVAL_MINUTES` | كل كم دقيقة يرسل (مثلاً 180) | اختياري |

3. Railway راح يبدأ التشغيل تلقائياً (في ملف `Procfile` يشغّله كـ worker).

---

## 📌 كيف أجيب ID القناة؟
1. في ديسكورد: **Settings → Advanced → Developer Mode** فعّليه.
2. كليك يمين على القناة → **Copy Channel ID**.
3. حطي الرقم في متغير `QUOTE_CHANNEL_ID`.

أو بسرعة: اكتبي في القناة `#قناة` (لازم تكوني مشرفة) والبوت يضبطها مؤقتاً، وبعدين انسخي الـ ID ثبّتيه في Railway عشان يبقى بعد إعادة التشغيل.

## 💬 الأوامر
| الأمر | الوظيفة |
|---|---|
| `#حكمة` | حكمة عشوائية |
| `#حكمة نجاح` | حكمة من تصنيف معيّن |
| `#قناة` أو `#قناة #اسم_القناة` | (للمشرفين) ضبط قناة الإرسال التلقائي |
| `#مساعدة` | عرض الأوامر |

## ➕ إضافة اقتباسات جديدة
افتحي ملف `quotes.json` وأضيفي عنصر جديد بنفس الشكل:
```json
{ "text": "نص الحكمة هنا", "author": "القائل", "category": "حياة" }
```
ثم ارفعي الملف وأعيدي النشر.
